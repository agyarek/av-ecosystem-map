Three ways to run the loop on a phone

The home page hides the circuit below 680px and serves a stacked list instead. The version before this one hid it below 700px, so there has never been a phone version — this is new work, not a restoration. Open this on your actual phone and tell me which one to build.

A · Portrait oval

The same circuit turned upright. Tallest of the three, and the only one where all four stations sit outside the road rather than on top of it.

B · Straight run, repeating

Not a loop at all: the car drives left to right past four stops and starts again. Shortest of the three, closest to how a phone actually scrolls, and it gives each station a full-width label.

C · The current loop, scaled down

Exactly what the desktop shows, shrunk to fit. Cheapest to ship because nothing changes, and the one where the car and the road detail get smallest.

All three use the same car and the same three-layer road as the desktop loop, so only the geometry differs.
